# Governance

ContextStream maintainers steward the project in public through GitHub issues,
pull requests, and releases. Maintainers may triage issues, review and merge
changes, manage security reports, and cut releases. Material protocol,
privacy-default, compatibility, or governance changes require at least two
maintainer approvals.

The public repository is the canonical source and release authority for the
Rust MCP core. Public tags are immutable. A private deployment repository may
pin and operate verified public artifacts but cannot publish or silently replace
the public source.

Maintainers must disclose relevant conflicts, follow the security process, and
recuse themselves where impartial review is not possible. Governance changes
are proposed through normal pull requests with a clear rationale and migration
impact.
